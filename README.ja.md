# Penguin Translate（Translation Overlay）

[简体中文](README.md) · [繁體中文](README.zh-TW.md) · [粵語](README.yue.md) · [日本語](README.ja.md) · [Français](README.fr.md) · [Português](README.pt.md)

Penguin Translate は Windows 向けのリアルタイム翻訳アプリです。別のウィンドウに表示された文字、システム音声、マイク入力を翻訳でき、翻訳文を使った発音練習もできます。

![ウィンドウ OCR 翻訳の例：左側が元の画面、右側が翻訳を重ねた画面](docs/media/window-ocr-demo.svg)

## 機能

- **ウィンドウ翻訳**：選択したウィンドウ内の文字を認識して翻訳し、元の画面に重ねて表示します。オーバーレイはマウス操作を遮りません。デスクトップと SteamVR に対応し、ショートカットキーでオン／オフを切り替えられます。
- **システム音声の字幕**：パソコンで再生中の音声を文字起こしして翻訳し、原文と訳文を専用の字幕バーに表示します。
- **マイク翻訳**：マイクから入った音声をリアルタイムで文字起こしして翻訳します。
- **発音練習**：翻訳文の音声を再生し、自分の音読を録音して採点します。日本語、中国語、韓国語では、それぞれの読み方も表示できます。

![Penguin Translate のメイン画面：中国語の音声を日本語と韓国語に翻訳し、返答を文字起こしして中国語に戻す例](docs/media/app-window-demo.svg)

## 発音練習

会話内の「このフレーズを練習」を選ぶと、対応する翻訳文が練習画面に入ります。音声例を再生し、録音ボタンを押しながら読み上げてください。ボタンを離すと、総合スコアと認識結果を確認できます。Penguin Cloud の評価を使う場合は、単語ごとのフィードバック、正確さ、流暢さ、完全さも表示されます。

![発音練習画面：日本語訳を選び、音声例を再生して録音し、採点結果を確認](docs/media/practice-mode-demo.svg)

## 対応言語

アプリの言語選択には、英語、日本語、簡体字中国語、繁体字中国語、広東語、呉語、韓国語、スペイン語、フランス語、ドイツ語、イタリア語、ポルトガル語、ロシア語があります。
