# 企鵝翻譯（Translation Overlay）

[简体中文](README.md) · [繁體中文](README.zh-TW.md) · [粵語](README.yue.md) · [日本語](README.ja.md) · [Français](README.fr.md) · [Português](README.pt.md)

企鵝翻譯是一款 Windows 即時翻譯應用程式。它可以翻譯其他視窗中的文字、將系統音訊轉錄並翻譯成字幕、翻譯麥克風輸入，以及用譯文練習發音。

![視窗 OCR 翻譯範例：左側為原始介面，右側為疊加顯示的譯文](docs/media/window-ocr-demo.svg)

## 功能

- **視窗翻譯**：選取視窗後，應用程式會辨識並翻譯畫面文字，再將譯文疊加在原始視窗上。浮動圖層不會攔截滑鼠操作，支援桌面和 SteamVR，也可以用快捷鍵開關。
- **系統音訊字幕**：轉錄並翻譯電腦正在播放的聲音，在獨立字幕列中顯示原文和譯文。
- **麥克風翻譯**：即時轉錄並翻譯麥克風收到的語音。
- **發音練習**：播放譯文的示範語音，錄下朗讀並提供評分。日文、中文和韓文可顯示對應的閱讀輔助。

![企鵝翻譯主畫面：中文語音被翻譯成日文和韓文，回覆則轉錄並譯回中文](docs/media/app-window-demo.svg)

## 發音練習

在對話中選擇「練習這句」，應用程式會將對應譯文載入練習畫面。播放示範語音後，按住錄音按鈕朗讀，放開即可查看總分和辨識結果。使用 Penguin Cloud 評分時，畫面還會顯示逐詞回饋、準確度、流利度和完整度。

![發音練習畫面：選取日文譯文、播放示範語音、錄音並查看評分](docs/media/practice-mode-demo.svg)

## 可選語言

應用程式的語言選擇器包括英文、日文、簡體中文、繁體中文、粵語、吳語、韓文、西班牙文、法文、德文、義大利文、葡萄牙文和俄文。
