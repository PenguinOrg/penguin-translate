# 企鹅翻译（Translation Overlay）

[简体中文](README.md) · [繁體中文](README.zh-TW.md) · [粵語](README.yue.md) · [日本語](README.ja.md) · [Français](README.fr.md) · [Português](README.pt.md)

企鹅翻译是一款 Windows 实时翻译应用。它可以翻译其他窗口中的文字、把系统音频转写并翻译成字幕、翻译麦克风输入，以及用译文练习发音。

![窗口 OCR 翻译示例：左侧为原界面，右侧为叠加显示的译文](docs/media/window-ocr-demo.svg)

## 功能

- **窗口翻译**：选定窗口后，应用会识别并翻译画面中的文字，再把译文叠加在原窗口上。悬浮层不会拦截鼠标操作，支持桌面和 SteamVR，也可以用快捷键开关。
- **系统音频字幕**：转写并翻译电脑正在播放的声音，在独立字幕条中显示原文和译文。
- **麦克风翻译**：实时转写并翻译麦克风收到的语音。
- **发音练习**：播放译文的示范语音，录下朗读并返回评分。日语、中文和韩语可显示对应的阅读辅助。

![企鹅翻译主界面：中文语音被翻译成日语和韩语，回复则转写并译回中文](docs/media/app-window-demo.svg)

## 发音练习

在对话中选择“练习这句”，应用会把对应译文载入练习界面。播放示范语音后，按住录音按钮朗读，松开即可查看总分和识别结果。使用 Penguin Cloud 评分时，界面还会显示逐词反馈、准确度、流利度和完整度。

![发音练习界面：选择日语译文、播放示范语音、录音并查看评分](docs/media/practice-mode-demo.svg)

## 可选语言

应用的语言选择器包括英语、日语、简体中文、繁体中文、粤语、吴语、韩语、西班牙语、法语、德语、意大利语、葡萄牙语和俄语。
